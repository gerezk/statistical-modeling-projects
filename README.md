# Statistical Modeling Projects

## Overview

This repository contains eleven assignments from the class 
"Advanced Methods in Regression and Classification" at TU Wien. 
The topics for each assignment are:

1. Linear regression
2. Model selection
3. Principal component regression (PCR) and L<sub>0</sub> norm regression
4. Partial least squares (PLS) and ridge regression
5. Comparison of shrinkage methods
6. Linear, quadratic, and regularized discriminant analysis (LDA, QDA, RDA)
7. Logistic regression and cross-validation
8. Basis expansions
9. B-splines and smoothing splines using the package splines
10. Generalized Additive Models (GAMs)
11. Classification trees and random forest
